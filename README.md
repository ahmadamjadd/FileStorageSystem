# Cloud File Storage Platform

A multi-user cloud file storage application built as a Cloud Computing & DevOps portfolio project.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Python, FastAPI, SQLAlchemy
- **Database:** PostgreSQL
- **Storage:** AWS S3
- **Auth:** JWT + bcrypt

## Architecture

```
React Frontend → FastAPI Backend → PostgreSQL (metadata)
                                 → AWS S3 (files)
```
